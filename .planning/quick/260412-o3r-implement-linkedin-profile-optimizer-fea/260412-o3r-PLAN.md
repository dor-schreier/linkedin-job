### PA-03: Add `get_linkedin_profile_analysis()` to groq_service

**Files:** `app/services/groq_service.py`

**Action:**
Add a new function `get_linkedin_profile_analysis(profile) -> dict` following the existing pattern of `get_profile_recommendations()`.

Constants to add at module level:

```python
LINKEDIN_ANALYSIS_SYSTEM_PROMPT = (
    "You are a LinkedIn profile optimization coach. Analyze the profile across exactly 8 sections "
    "and return ONLY valid JSON, no other text, no markdown code fences.\n"
    'Schema: {"sections": [{"name": "<section>", "score": <int 0-100>, "tasks": ["<task>", ...]}, ...], '
    '"overall_score": <int 0-100>, "top_priority": "<single most impactful change>"}\n'
    "The 8 sections MUST be: Headline, About / Summary, Experience Bullets, Skills Section, "
    "Featured Section, Recommendations, Keyword Density, Profile Completeness.\n"
    "Each section: score 0-100, 2-4 concrete actionable tasks.\n"
    "overall_score: weighted average across sections.\n"
    "top_priority: the single most impactful change to make first."
)

LINKEDIN_ANALYSIS_SAFE_FALLBACK: dict[str, Any] = {
    "sections": [],
    "overall_score": None,
    "top_priority": None,
}
```

Function implementation:
- Build user prompt with all profile fields (linkedin_url, current_title, target_title, years_experience, skills) — same field access pattern as `get_profile_recommendations`
- Call `_get_client().chat.completions.create()` with `model=RECOMMEND_MODEL`, `max_tokens=2048` (larger than usual — 8 sections of tasks)
- Parse response with `_strip_code_fence` then `json.loads`
- Validate: ensure `sections` is a list, each has `name`/`score`/`tasks`, `overall_score` is int, `top_priority` is str
- On any error, log warning and return `LINKEDIN_ANALYSIS_SAFE_FALLBACK`

Add a private helper `_parse_linkedin_analysis_response(content: str) -> dict` for the parsing/validation.

**Verify:** `python -c "from app.services.groq_service import get_linkedin_profile_analysis, LINKEDIN_ANALYSIS_SAFE_FALLBACK; print('OK')"`

**Done:** Function exists, importable, returns structured dict or safe fallback.

### PA-04: Add `upsert_profile_analysis()` to repository

**Files:** `app/repository.py`

**Action:**
Add method to `JobRepository` class in the `# --- Profile ---` section:

```python
def upsert_profile_analysis(self, analysis_json: str) -> Profile:
    """Save linkedin analysis JSON and set analyzed_at timestamp."""
    from datetime import datetime, timezone
    profile = self.session.query(Profile).first()
    if profile:
        profile.linkedin_analysis = analysis_json
        profile.linkedin_analyzed_at = datetime.now(timezone.utc)
        self.session.commit()
        self.session.refresh(profile)
    return profile
```

**Verify:** `python -c "from app.repository import JobRepository; assert hasattr(JobRepository, 'upsert_profile_analysis'); print('OK')"`

**Done:** Method exists and saves JSON + timestamp to profile.
