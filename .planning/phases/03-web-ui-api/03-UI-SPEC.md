1. Primary CTA button ("Run Scrape", "Save Status")

1. "Rejected" job status badge text
2. Scrape error message text
3. No delete actions exist in Phase 3 — no confirmation dialogs needed

## Component Inventory

Phase 3 introduces these new UI patterns. Each must be implemented as Jinja2 template fragments + Tailwind classes.

### Nav Bar

- Top bar spanning full width
- bg-white, border-b border-gray-200, px-6 py-3
- App name left: "Job Finder" text-lg font-bold text-gray-800
- Nav links right: Jobs | Profile | Search Config | Watch Rules
- Active link: text-blue-600 font-medium border-b-2 border-blue-600
- Inactive link: text-gray-600 hover:text-gray-900
- All 4 nav links must resolve (UI-03) — Profile and Watch Rules can be placeholder pages in Phase 3

### Job Card (list row)

Each job rendered as a card row in the jobs list:

- bg-white rounded-lg border border-gray-200 p-4
- Title: text-base font-semibold text-gray-800
- Company + Location: text-sm text-gray-600 (one line, "Company · Location")
- Source badge: text-xs bg-gray-100 text-gray-600 px-2 py-0.5 rounded (e.g. "LinkedIn")
- Salary (if present): text-sm text-gray-700 (JOBS-05 — display actual value; no estimate in Phase 3)
- Scraped date: text-xs text-gray-400
- Status dropdown: inline `<select>` text-sm, Tailwind select styling (see below)
- Apply link: text-sm text-blue-600 underline "View Job" — opens in new tab

### Status Dropdown (JOBS-06)

Inline `<select>` on each job card:

```html
<select
  hx-post="/jobs/{id}/status"
  hx-swap="none"
  class="border border-gray-300 rounded px-2 py-1 text-sm focus:outline-none focus:ring-2 focus:ring-blue-500"
>
  <option value="">— Set Status —</option>
  <option value="saved">Saved</option>
  <option value="applied">Applied</option>
  <option value="interviewing">Interviewing</option>
  <option value="offer">Offer</option>
  <option value="rejected">Rejected</option>
</select>
```

Status badge colors (read display next to dropdown after status set):

| Status | Badge classes |
|--------|--------------|
| saved | bg-blue-100 text-blue-700 |
| applied | bg-yellow-100 text-yellow-700 |
| interviewing | bg-purple-100 text-purple-700 |
| offer | bg-green-100 text-green-700 |
| rejected | bg-red-100 text-red-600 |

### Filter Bar (JOBS-07)

Horizontal filter bar above job list, rendered as HTMX-enhanced form:

- hx-get="/jobs" hx-trigger="change" hx-target="#job-list" hx-swap="innerHTML"
- Filters: Status `<select>`, Company `<input type="text">`, Salary Min `<input type="number">`
- Each filter: label + input, text-sm, same border/focus classes as form fields
- Reset button: text-sm text-gray-500 underline, clears all filters

### Pagination / Load More

- Simple "Load more" button at bottom of list (or page numbers if under 50 results)
- Button: text-sm text-blue-600 border border-blue-600 rounded px-4 py-2 hover:bg-blue-50
- HTMX: hx-get with page param, hx-swap="beforeend" appends to list

## Interaction Contract

### HTMX Patterns

All dynamic updates use HTMX. No custom JavaScript unless absolutely unavoidable.

| Interaction | Trigger | Target | Swap |
|-------------|---------|--------|------|
| Filter jobs | change on any filter input | #job-list | innerHTML |
| Set job status | change on status select | none (silent POST) | none |
| Poll scrape status | every 2s while running | #scrape-result | outerHTML |
| Load more jobs | click | #job-list | beforeend |

### Loading States

- Scrape in progress: `animate-pulse text-blue-600` on status div (already established)
- Filter loading: `htmx-indicator` class — add `opacity-50` to #job-list while request in flight
  - Add `hx-indicator="#job-list"` and CSS `.htmx-request { opacity: 0.5; transition: opacity 0.2s; }`

### Focus and Accessibility

- All interactive elements must have visible focus rings: `focus:outline-none focus:ring-2 focus:ring-blue-500`
- Form labels must use `for` attribute matching input `id`
- Status select must have a descriptive `aria-label="Job status for {title}"`
- Nav links must use `<a>` not `<button>`
- Page `<title>` must match nav link label: "Job Finder — Jobs", "Job Finder — Search Config", etc.
