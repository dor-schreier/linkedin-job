Create `app/scraper.py` with these components:

1. `RESULTS_WANTED = 50` constant at module level.

2. `_compute_hash(title: str, company: str, location: str) -> str`:
   - Builds `f"{title}|{company}|{location}".lower().strip()`
   - Returns `hashlib.sha256(raw.encode()).hexdigest()`

3. `_normalize_row(row: dict) -> Optional[dict]`:
   - Extracts fields using `row.get("field")` pattern (NEVER `row["field"]`)
   - String fields: `str(row.get("title") or "").strip()` — coerces NaN to ""
   - Numeric salary: `val = row.get("min_amount"); salary_min = float(val) if val is not None and str(val) != "nan" else None`
   - Same for `max_amount` -> `salary_max`, `currency` -> `salary_currency`
   - `source` from `row.get("site")`, `apply_url` from `row.get("job_url")`
   - Returns `None` if `is_remote` is True (SRCH-04 filter)
   - Returns `None` if `title` is empty after strip
   - Computes `job_hash` via `_compute_hash(title, company, location)`
   - Returns dict with keys: title, company, location, description, source, apply_url, salary_min, salary_max, salary_currency, job_hash

4. `run_scrape(keywords: str, location: str, experience_level: Optional[str] = None, country_indeed: str = "USA") -> dict`:
   - Builds `search_term`: if `experience_level` provided, prepend it to keywords (e.g., "senior software engineer")
   - Calls `scrape_jobs(site_name=["linkedin", "indeed", "glassdoor"], search_term=search_term, location=location, country_indeed=country_indeed, job_type="fulltime", results_wanted=RESULTS_WANTED, verbose=0, linkedin_fetch_description=True)`
   - Creates its OWN session: `with SessionLocal() as session:` (NEVER accept session from caller)
   - Iterates `df.iterrows()`, calls `_normalize_row()` for each
   - Skips if `_normalize_row()` returns None
   - Checks `repo.get_job_by_hash(normalized["job_hash"])` — skips if exists
   - Calls `repo.add_job(**normalized)` for new jobs
   - Returns `{"total_scraped": len(df), "inserted": N, "skipped": N, "remote_filtered": N}`
   - Wraps entire function in try/except, logs errors, returns `{"error": str(e)}` on failure

5. Import: `import hashlib`, `import logging`, `from typing import Optional`, `from jobspy import scrape_jobs`, `import math` (for `math.isnan` as fallback), `from app.database import SessionLocal`, `from app.repository import JobRepository`

```python
"""CLI entrypoint to validate scraper pipeline without the web server."""
import sys
import os

# Add project root to path so app imports work
sys.path.insert(0, os.path.dirname(os.path.dirname(os.path.abspath(__file__))))

from app.database import init_db
from app.scraper import run_scrape

def main():
    print("Initializing database...")
    init_db()

    keywords = sys.argv[1] if len(sys.argv) > 1 else "software engineer"
    location = sys.argv[2] if len(sys.argv) > 2 else "New York"

    print(f"Scraping: keywords='{keywords}', location='{location}'")
    result = run_scrape(keywords=keywords, location=location)
    print(f"Result: {result}")

    if "error" in result:
        print(f"ERROR: {result['error']}")
        sys.exit(1)

    print(f"Inserted {result['inserted']} new jobs, skipped {result['skipped']}")

if __name__ == "__main__":
    main()
```
