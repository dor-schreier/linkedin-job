Create `app/routes/scrape.py` with:

1. Module-level state dict: `_scrape_status: dict = {"running": False, "last_result": None, "error": None}`

2. `GET /scrape` — renders `scrape.html` template:
   - Uses `Depends(get_session)` to get a session
   - Creates `JobRepository(session)` and calls `repo.list_search_configs(active_only=True)`
   - Takes the first config (if any) as `latest_config`, else `None`
   - Passes `request`, `latest_config`, `status=_scrape_status` to template

3. `POST /scrape/run` — triggers background scrape:
   - Accepts `Form` fields: `keywords: str`, `location: str`, `experience_level: str = ""`, `work_mode: str = ""`
   - Uses `Depends(get_session)` to save search config via `repo.add_search_config(keywords=keywords, location=location, experience_level=experience_level or None, work_mode=work_mode or None, is_active=True)`
   - If `_scrape_status["running"]` is True, return HTML fragment: `<div id="scrape-result" class="text-yellow-600">A scrape is already running.</div>`
   - Otherwise, call `background_tasks.add_task(_run_scrape_task, keywords, location, experience_level or None)`
   - Return HTML fragment: `<div id="scrape-result" hx-get="/scrape/status" hx-trigger="every 2s" hx-swap="outerHTML" class="text-blue-600">Scrape started...</div>`

4. `_run_scrape_task(keywords: str, location: str, experience_level: Optional[str])` — module-level function:
   - Sets `_scrape_status["running"] = True`, `_scrape_status["error"] = None`
   - Calls `run_scrape(keywords=keywords, location=location, experience_level=experience_level)`
   - On success: `_scrape_status["last_result"] = result`
   - On exception: `_scrape_status["error"] = str(e)`
   - Finally: `_scrape_status["running"] = False`

5. `GET /scrape/status` — returns HTML fragment for HTMX polling:
   - If `_scrape_status["running"]`: return `<div id="scrape-result" hx-get="/scrape/status" hx-trigger="every 2s" hx-swap="outerHTML" class="text-blue-600 animate-pulse">Scraping in progress...</div>`
   - If `_scrape_status["error"]`: return `<div id="scrape-result" class="text-red-600">Error: {error}</div>`
   - If `_scrape_status["last_result"]`: return `<div id="scrape-result" class="text-green-600">Done! Inserted {inserted}, skipped {skipped} (from {total_scraped} scraped)</div>`
   - Else: return `<div id="scrape-result" class="text-gray-500">No scrape run yet.</div>`

| T-02-06 | Denial of Service | app/routes/scrape.py _scrape_status | mitigate | _scrape_status["running"] flag prevents concurrent scrapes; single background task at a time |
| T-02-07 | Information Disclosure | GET /scrape/status | accept | Status endpoint returns scrape counts and error messages; acceptable for personal local app with no auth |
| T-02-08 | Spoofing | POST /scrape/run | accept | No auth required — personal single-user POC, no multi-tenancy |
